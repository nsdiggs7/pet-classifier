# Nate's Pet Classifier

Interactive Pet Classifier built with React, TypeScript, FastAPI, and TensorFlow. Users upload images to get predictions among 37 pet breeds, trained on 3680+ Oxford-IIIT Pet images, achieving 87% validation accuracy, with a responsive front-end displaying images and predictions.

## To run application

### Start backend

Open a terminal and enter these commands:

```bash
cd pet-classifier/backend
uvicorn main:app --reload
```

### Start frontend

Open a different terminal and enter these commands

```bash
cd pet-classifier/fronted
npm install
npm run dev
```
